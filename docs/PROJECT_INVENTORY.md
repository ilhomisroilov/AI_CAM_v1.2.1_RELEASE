## Cleanup performed

- Removed project `__pycache__/` directories and `.pytest_cache/`; both are regenerated.
- Removed tracked and untracked `.idea/` metadata; IntelliJ/PyCharm regenerates it.
- Removed the tracked `__probe.txt` probe artifact.
- Consolidated exact duplicate Markdown files under `docs/`: the root copies of
  `OCR_MIGRATION_REPORT.md`, `PLC_AND_CONFIG.md` and `VIN_OCR_PIPELINE.md` were removed only
  after matching hashes confirmed that `docs/` held byte-identical copies. The PLC document was
  then updated to the current D2222 pulse/bit architecture.
- Updated `.gitignore` for runtime caches, IDE files, local data ZIPs, `data/crrr/`, diagnostic
  contact sheets and local migration snapshots.

Tracked deletions are recoverable from Git. Ignored cache/IDE files are not source and are
regenerated by Python, pytest or the IDE.

## Intentionally preserved

- `data/crops/`, `data/*.zip`, `data/crrr/`, `data/ai_cam.db` and contact sheets;
- all `dataset/**` images and labels, including apparent copies between `images_raw/` and
  `collected_raw/**`;
- `models/**`, `runs/**/weights/**` and the repository YOLO weights;
- logs, evidence XML/JSON/TXT files, workflow/animation sources and the project presentation;
- backup manifests and dependency-freeze snapshots.

Several dataset files have matching names and sizes in `dataset/images_raw/` and split folders.
They may be deliberate source-versus-split copies. Do not deduplicate them until a dataset
manifest proves ownership, split membership and label pairing; deleting only an image or only a
label would corrupt training data.
